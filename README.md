# CNC Master

Android-помощник наладчика токарных ЧПУ.

## v0.1

- расчёт оборотов шпинделя по Vc и диаметру;
- расчёт подачи в мм/мин;
- обратный расчёт скорости резания;
- заготовки модулей «Резьбы», «Материалы», «Инструмент», «Диагностика»;
- тёмный интерфейс для работы у станка;
- встроенная система обновлений без браузера.

## Встроенные обновления

CNC Master проверяет `update/version.json` при запуске и дополнительно раз в ~6 часов через WorkManager.

Если новая версия доступна:

1. приложение показывает её номер и changelog;
2. кнопка **«Скачать и обновить»** загружает APK внутри приложения;
3. отображается реальный процент загрузки;
4. APK проверяется по размеру и SHA-256;
5. Android открывает системное окно установки;
6. при первом обновлении Android может попросить разрешение «Установка неизвестных приложений» для CNC Master.

Обновления публикуются GitHub Actions: подписанный APK попадает в GitHub Release, а `update/version.json` автоматически обновляется ссылкой, SHA-256, размером и changelog.

## Постоянная подпись APK

Чтобы новые APK устанавливались поверх старых, каждый release должен быть подписан одним и тем же ключом. В GitHub repository secrets должны быть:

- `CNC_KEYSTORE_BASE64`
- `CNC_KEYSTORE_PASSWORD`
- `CNC_KEY_ALIAS`
- `CNC_KEY_PASSWORD`

В репозитории есть `scripts-create-signing-key.ps1`, который создаёт ключ локально. Сам `.jks` нельзя коммитить в публичный репозиторий.

## Обновление changelog

Перед следующим релизом редактируется `update-changelog.txt`. После push в `main` workflow собирает APK и публикует новую версию.
