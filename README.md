# CNC Master

Android-помощник наладчика токарных ЧПУ: расчёты, резьбы, Fanuc 0i-TF, диагностика, локальные технологические журналы и AI-редактор NC-кода.

Текущий публичный релиз: **v0.2.1**.

## Что реализовано в v0.2.1

### Умные режимы

По материалу, операции, диаметру, радиусу вершины и стратегии CNC Master рассчитывает стартовые:

- скорость резания Vc;
- обороты RPM;
- подачу на оборот f;
- линейную подачу F;
- глубину резания ap.

Это консервативные стартовые рекомендации, а не замена каталогу конкретной пластины.

### Резьбы

- базовая геометрия метрической резьбы 60°;
- ISO 965 coarse/fine;
- UNC и UNF с переводом inch ↔ mm;
- BSPP / G по ISO 228-1;
- BSPT / R по ISO 7-1;
- NPT по ASME B1.20.1 как справочник идентификации;
- предупреждение о несовместимости BSPT и NPT;
- расчёт среднего и малых диаметров;
- приближённый диаметр сверла D−P;
- радиальная высота профиля для G76.

### Fanuc 0i-TF

- проверочный шаблон двухстрочного G76;
- последовательность проходов G92;
- наружная/внутренняя резьба;
- правая/левая резьба;
- ввод G97 S;
- копирование G76/G92;
- предупреждения для Single Block / Dry Run.

CNC Master намеренно не подставляет M03/M04 автоматически для левой резьбы: это зависит от ориентации инструмента и конкретного станка.

### Диагностика

Справочник по flank/edge wear, chipping, built-up edge, crater wear, thermal deformation, vibration/chatter и size drift/taper.

Для каждого симптома показываются вероятные причины, что проверить первым и какие изменения вносить.

### Инструмент и «Мои детали»

- справочник типовых пластин и геометрий;
- локальный журнал стойкости;
- материал, Vc, f, ap, количество деталей и причина замены;
- локальные технологические карточки деталей;
- станок, номер программы, время цикла и заметки по наладке.

### AI-программист

В v0.2.1 добавлены:

- отдельный экран AI-программиста;
- ввод станка, стойки, материала, заготовки, инструмента, зажима и нуля детали;
- редактор NC-кода;
- backend API `POST /v1/cnc/generate`;
- локальный анализ рисков G-кода;
- проверка G96 без G50, отрицательного X, G28/G53/G10, макросов, G41/G42, G76/G92 и нестандартных M-кодов;
- копирование подготовленного кода;
- ASCII/CRLF-нормализация;
- экспорт `.NC` через системный выбор файла, включая USB OTG;
- обязательное предупреждение о проверке Graphics / Single Block / Dry Run.

AI-код считается только черновиком. Приложение не подтверждает отсутствие столкновений и не запускает станок удалённо.

## AI backend

Backend теперь использует provider layer: Android работает с единым CNC API, а конкретная нейросеть выбирается сервером через `CNC_AI_PROVIDER`. Текущий provider — OpenAI Responses API; Local AI будет подключён на M3.2 без изменения Android-контракта.

Основные переменные:

- `CNC_AI_PROVIDER` — активный provider (`openai` на M3.1);
- `OPENAI_API_KEY` — ключ OpenAI provider;
- `OPENAI_MODEL` — выбранная модель;
- `CNC_APP_TOKEN` — необязательный общий токен для временного ограничения доступа.

Android-сборка может получить тот же `CNC_APP_TOKEN` и отправляет его в заголовке `X-CNC-App-Token`.

**Важно:** общий токен, встроенный в APK, нельзя считать надёжной пользовательской авторизацией — его можно извлечь из приложения. Он предназначен только как промежуточная защита при разработке. В M3.3 предусмотрена полноценная авторизация, rate limit и индивидуальные сессии.

## Встроенные обновления

CNC Master проверяет `update/version.json` при запуске и дополнительно через WorkManager.

Если новая версия доступна:

1. показывается версия и changelog;
2. APK загружается внутри приложения;
3. отображается прогресс;
4. проверяются размер и SHA-256;
5. Android открывает системную установку.

Релизные APK подписываются постоянным ключом, поэтому новая версия может устанавливаться поверх старой.

## CI/CD

На pull request выполняются:

1. Python syntax-check AI backend;
2. JUnit unit tests;
3. Android lint.

На push в `main` дополнительно собирается debug APK. Новые debug-артефакты хранятся 3 дня, signed release artifact — 14 дней; опубликованные APK остаются в GitHub Releases.

Публичный релиз создаётся только через `workflow_dispatch` или commit marker `[release X.Y.Z]`.
