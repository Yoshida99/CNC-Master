# CNC Master

Android-помощник наладчика токарных ЧПУ. Основные расчёты, справочники и пользовательские журналы работают офлайн.

## v0.2

### Умные режимы

По материалу, операции, диаметру, радиусу вершины и стратегии CNC Master рассчитывает стартовые:

- скорость резания Vc;
- обороты RPM;
- подачу на оборот f;
- линейную подачу F;
- глубину резания ap.

Это консервативные стартовые рекомендации, а не замена каталогу конкретной пластины.

### Резьбы

- базовая геометрия метрической резьбы 60°;
- ISO 965 coarse/fine;
- UNC и UNF с переводом inch ↔ mm;
- BSPP / G по ISO 228-1;
- BSPT / R по ISO 7-1;
- NPT по ASME B1.20.1 как справочник идентификации;
- предупреждение о несовместимости BSPT и NPT;
- расчёт среднего и малых диаметров;
- приближённый диаметр сверла D−P;
- радиальная высота профиля для G76.

### Fanuc 0i-TF

- проверочный шаблон двухстрочного G76;
- последовательность проходов G92;
- наружная/внутренняя резьба;
- правая/левая резьба;
- ввод G97 S;
- копирование G76/G92 в буфер;
- предупреждения для Single Block / Dry Run.

CNC Master намеренно не подставляет M03/M04 автоматически для левой резьбы: это зависит от ориентации инструмента и конкретного станка.

### Диагностика

Справочник по:

- flank/edge wear;
- chipping;
- built-up edge;
- crater wear;
- thermal deformation;
- vibration/chatter;
- size drift/taper.

Для каждого симптома показываются вероятные причины, что проверить первым и какие изменения вносить.

### Инструмент

- быстрый справочник по типовым пластинам и геометриям;
- локальный журнал стойкости;
- материал, Vc, f, ap, количество деталей и причина замены;
- записи сохраняются на телефоне.

### Мои детали

Локальные технологические карточки:

- название детали;
- материал;
- станок;
- номер программы;
- время цикла;
- заметки по наладке.

## Источники справочных данных

- Seco Tools — ISO Material Groups / SMG;
- TR Fastenings — metric coarse/fine, UNC и UNF thread geometry;
- ISO 228-1 reference dimensions for BSPP/G;
- Swagelok Thread and End Connection Identification Guide — BSPT/ISO 7-1 и NPT identification;
- Kennametal — turning troubleshooting guidance;
- Fanuc 0i-TF Operator Manual format for G92/G76.

Числа по режимам в CNC Master предназначены как консервативная отправная точка. Финальный режим всегда должен учитывать конкретную пластину, марку твёрдого сплава, СОЖ, жёсткость станка, вылет и состояние заготовки.

## Проверка качества v0.2

CI на каждом изменении выполняет:

1. JUnit unit tests;
2. Android lint;
3. полноценную debug APK сборку.

Дополнительно в `QA_V0.2.md` находится чек-лист ручной проверки на реальном Android-устройстве перед подписанным релизом.

## Встроенные обновления

CNC Master проверяет `update/version.json` при запуске и дополнительно раз в ~6 часов через WorkManager.

Если новая версия доступна:

1. приложение показывает номер версии и changelog;
2. кнопка **«Скачать и обновить»** загружает APK внутри приложения;
3. отображается реальный прогресс;
4. APK проверяется по размеру и SHA-256;
5. Android открывает системное окно установки.

Обычные push в `main` выполняют тесты, lint и debug-сборку. Подписанный публичный релиз создаётся вручную через GitHub Actions `workflow_dispatch`, чтобы технические commits не становились обновлениями для пользователей.

## Постоянная подпись APK

Чтобы новые APK устанавливались поверх старых, каждый release должен быть подписан одним и тем же ключом. В GitHub repository secrets должны быть:

- `CNC_KEYSTORE_BASE64`
- `CNC_KEYSTORE_PASSWORD`
- `CNC_KEY_ALIAS`
- `CNC_KEY_PASSWORD`

В репозитории есть `scripts-create-signing-key.ps1`. Сам `.jks` нельзя коммитить в публичный репозиторий.
