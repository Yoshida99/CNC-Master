# CNC Master v0.2.1 — acceptance checklist

Актуальный чек-лист для v0.2.1 и технической стабилизации M2.2.

## Навигация

- Открыть каждый раздел главного экрана и вернуться стрелкой.
- Повторить через системную кнопку/жест «Назад».
- Убедиться, что приложение выходит только при Back с главного экрана.
- Открыть AI-программист и вернуться обоими способами.

## Основные расчёты

- Проверить RPM и feed rate на заранее рассчитанных значениях.
- Проверить ввод с точкой и запятой.
- Пустые/некорректные поля не должны приводить к crash.
- Проверить несколько материалов и стратегий резания.

## Резьбы и Fanuc

- M12×1: проверить базовую геометрию.
- Проверить ISO fine/coarse, UNC/UNF, BSPP, BSPT и NPT.
- Убедиться, что BSPT и NPT не показываются как взаимозаменяемые.
- Проверить G76 и G92 для наружной/внутренней и правой/левой резьбы.
- Убедиться, что направление M03/M04 не придумывается автоматически.

## AI-программист — offline

- Сборка без `CNC_AI_BACKEND_URL`: редактор NC, локальная проверка и экспорт работают.
- Кнопка AI сообщает, что backend не подключён.
- Ввести программу с G96 без G50: должен появиться критический флаг.
- Ввести отрицательный X: должен появиться критический флаг.
- Проверить G28/G53/G10, макросы, G41/G42, G76/G92 и нестандартный M-код.
- Проверить имя файла из O-номера.
- Проверить преобразование кириллицы в ASCII-compatible экспорт.
- Экспорт без подтверждения ручной проверки должен быть недоступен.

## AI backend — connection/auth

- `GET /health` возвращает `ok=true`, provider, model, `ai_configured` и `auth_required`.
- Backend без `CNC_APP_TOKEN`: запрос проходит без заголовка.
- Backend с `CNC_APP_TOKEN`: запрос без токена получает 401.
- Android-сборка с тем же `CNC_APP_TOKEN`: заголовок `X-CNC-App-Token` отправляется и запрос принимается.
- Пустой app token не должен создавать заголовок.
- Неверный/недоступный backend показывает понятную ошибку без crash.
- Timeout не должен зависать бесконечно.

> Общий `CNC_APP_TOKEN` — временная защита для разработки. Он не считается безопасной публичной авторизацией, потому что значение может быть извлечено из APK.

## AI-ответ и NC-код

- Структурированный ответ корректно заполняет explanation, code, warnings и assumptions.
- Некорректный JSON от модели не должен создавать NC-файл автоматически.
- Сгенерированный код всегда помечается как черновик.
- Неизвестные параметры станка/зажима/инструмента должны приводить к уточнению, а не к выдуманным значениям.
- Для G96 без известного безопасного spindle clamp AI не должен придумывать значение.

## Экспорт USB

- Сохранить обычный `.NC` во внутреннюю память.
- Подключить USB OTG и сохранить на флешку через системный picker.
- Проверить CRLF и 7-bit ASCII.
- Убедиться, что приложение не обещает «готовность к запуску».

## Обновления

- Ручная проверка новой версии работает.
- Неверный SHA-256 блокирует установку.
- Правильный APK открывает package installer.
- Новая подписанная версия устанавливается поверх 0.2.1 без удаления данных.

## Release gate

Перед следующим публичным релизом:

1. JUnit green.
2. Android lint green.
3. Python backend syntax-check green.
4. QA v0.2.1 пройден на реальном Android.
5. Проверен путь обновления поверх установленной 0.2.1.
6. Постоянный signing key доступен.
7. Проверена конфигурация AI backend для выбранного релиза.
